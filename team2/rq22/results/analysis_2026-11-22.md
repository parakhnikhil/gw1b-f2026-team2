# GW-1B provisional validation-loss predictions

Run from the repository root with Python, NumPy, and SciPy.

```bash
python team2/rq22_snapshot.py team2/rq22/results/completed_inputs_2026-11-22.csv
```

The CSV records 15 finished runs from Pegasus summaries. Each primary fit uses
10 runs, with three observations for one 50M shape and seven shared observations
from the 100M, 200M, and 350M models. The two extra 100M-t20 seeds enter only
the sensitivity check. The 200M-t30 and 350M-t30 summaries were unavailable.

| 50M shape | 1.15B at 20B tokens | 1.15B at 23B tokens | 23B including extra seeds |
| --- | ---: | ---: | ---: |
| Original | 2.3511 | 2.3414 | 2.3423 |
| 576×9 | 2.3810 | 2.3713 | 2.3722 |

The predictions use the repository's default log-Huber parametric fit. The 20B
column records the original assignment target. The 23B column matches the
reported Team 3 production budget.

For the 200M holdout, the fit uses only the 50M and 100M points with alpha
fixed at 0.34. Errors below are predicted minus observed loss.

| Run | Observed | Original prediction (error) | 576×9 prediction (error) |
| --- | ---: | ---: | ---: |
| 200M-t10 | 2.8040 | 2.8371 (+0.0331) | 2.8189 (+0.0149) |
| 200M-t20 | 2.6993 | 2.7552 (+0.0559) | 2.7363 (+0.0370) |

## Provisional bootstrap at 1.15B parameters and 23B tokens

Reproduce from the repository root with `python3 -u team2/rq22_bootstrap.py`.

| Fit | Point estimate | Bootstrap median | 90% bootstrap range | Fits at a parameter bound |
| --- | ---: | ---: | ---: | ---: |
| Original 50M | 2.3414 | 2.3437 | 2.2895–2.4267 | 43/300 |
| Alternate 576×9 | 2.3713 | 2.3727 | 2.3100–2.4356 | 28/300 |

All 300 paired draws were retained. The paired difference (alternate minus
original) had a median of +0.0283 and a 90% range of +0.0025 to +0.0333.
The bootstrap resamples token-budget settings within each model size and
seeds within 100M-t20. The ranges exclude extrapolation error at 1.15B.

The fitting-method comparison and the test against Team 3's measured loss
remain open.
